# AI Regulations Comparison Dashboard

**VAC Capstone Project**  
A beginner-friendly static web application comparing selected AI governance themes in India and the European Union.

## Features
- Responsive comparison dashboard
- Five comparison themes: overall approach, risk management, transparency, accountability, and innovation
- Search across comparison text
- Filter by theme
- Links to official source websites
- Educational-use disclaimer

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run the project
1. Download and extract this project folder.
2. Open `index.html` in a modern browser such as Chrome or Edge.
3. Use the theme dropdown and search field to explore the comparison.

No server or package installation is required.

## Important research note
The India column is intentionally cautious: India's AI governance framework includes policies and guidance that may evolve. Do not describe it as identical to the EU AI Act or claim a single comprehensive Indian AI-specific law without checking official sources. Verify current official documents and dates before final submission.

## Official references
- Ministry of Electronics and Information Technology (India): https://www.meity.gov.in/
- European Commission AI Act overview: https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai
- European Commission AI Act FAQ: https://digital-strategy.ec.europa.eu/en/faqs/navigating-ai-act
