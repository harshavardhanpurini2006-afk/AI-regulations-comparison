## 1. Abstract
Artificial Intelligence is increasingly used in education, healthcare, finance, employment and public services. Responsible AI governance helps address issues such as safety, fairness, privacy, transparency and accountability. This project develops a simple web dashboard that presents an educational comparison of selected AI governance themes in India and the European Union. Users can search the comparison text and filter by theme. The application is built using HTML, CSS and JavaScript and links to official sources for further reading.

## 2. Introduction
AI systems can provide benefits, but they may also create risks when used in sensitive contexts. Governments and public institutions develop governance approaches to encourage beneficial AI use while addressing risks. Understanding the similarities and differences between regions helps students learn the basics of AI policy.

## 3. Problem Statement
Information about AI governance is distributed across official policy pages and legal documents. Beginners may find it difficult to compare regions and locate reliable sources. This project presents a small, searchable dashboard to make an introductory comparison easier to explore.

## 4. Objectives
- Present an introductory comparison of India and the European Union.
- Organise information under clear themes.
- Provide search and filtering features.
- Link to official sources for verification.
- Demonstrate the use of HTML, CSS and JavaScript to build a responsive web application.

## 5. Scope
The dashboard is an educational overview, not a complete legal analysis or legal advice tool. It focuses on five themes: overall approach, risk management, transparency, accountability and innovation. The project does not determine whether a specific company or AI system is legally compliant.

## 6. Technologies Used
- HTML5: page structure and content.
- CSS3: layout, visual design and responsive styling.
- JavaScript: rendering comparison rows, search and theme filtering.
- Web browser: running and testing the application.
- Git and GitHub: version control and code hosting (to be completed by the student).

## 7. Methodology
1. Identify comparison themes relevant to AI governance.
2. Find official government and European Commission sources.
3. Summarise the themes in accessible language while avoiding unsupported legal claims.
4. Create the dashboard structure in HTML.
5. Style the dashboard with CSS.
6. Use JavaScript to render, filter and search comparison data.
7. Test the dashboard on a laptop browser.
8. Publish the source code in a GitHub repository and include the repository URL in the final report.
